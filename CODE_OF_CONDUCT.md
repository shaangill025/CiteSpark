# Code of Conduct

We follow the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful, assume good faith, give and accept constructive feedback, and do not harass or discriminate.

Report concerns privately to the maintainer through GitHub (profile contact or a private security advisory).
Maintainers may remove content and restrict participation that violates these expectations.

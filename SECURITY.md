# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting
(Security tab, "Report a vulnerability") on this repository. Include the affected version or commit, reproduction
steps, and impact. Do not include real credentials or private library data; use synthetic examples.

We aim to acknowledge reports within 7 days. This is a best-effort project with no bug bounty.

## Status and scope

The project is at specification stage; there is no released software. Once previews ship, only the latest
preview is supported. The security requirements are in spec section 11 (SEC-01 to SEC-08). Release blockers:
zero data loss, zero credential disclosure, and zero protected-content upload.

## Out of scope

A fully compromised operating system, and data in vault or backup copies the user made outside Citspark.
